# WorkSpec documentation

WorkSpec describes a world, planned work, executable effects, and rules that inspect the resolved result.

## Start with a working project

New to WorkSpec? Follow the short path from installation to a validated and rendered project.

1. [Understand what WorkSpec does](/docs/start/what-is-workspec/).
2. [Install and verify WorkSpec](/docs/start/install/).
3. [Build your first WorkSpec project](/docs/start/first-project/).

## Learn the language

The [Learn WorkSpec path](/docs/learn/world-state/) teaches canonical WorkSpec 2.2 in a linear sequence. It starts with world state and introduces causal Generator logic last.
