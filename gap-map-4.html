03 / MODEL

WorkSpec research gaps, freshly framed

The current package is a credible evaluator of authored histories. It is not yet the jigsaw-solving or simulator-inference system described in the meeting.

Decision

Define “simple curve” precisely

Today’s Changes are discrete task-start/task-completion effects. They cannot inspect world state, which is good; however, there is no first-class f(parameters, time) → value curve, and change() applies a delta to prior value.

Strong restriction: proven
Continuous curve model: absent
Delta semantics: state-relative
John + research designsettle before API expansion
Architecture

Random access still replays

Snapshot and render call runProject(... until: T) and then sample history. They answer the query truthfully, but do not yet provide direct evaluation at T without prior execution.

runProject → replay
snapshotRunAt samples completed run
Research milestoneafter curve semantics
FYP core

No optimiser/search loop

Constraints report invalidity and Changes/Generator can create, move, mutate, or remove objects, but nothing proposes edits, scores candidate histories, or searches until all constraints pass.

Evaluator primitives: present
Search/objective/repair protocol: absent
Final-year projectprimary technical contribution
FYP core

No bakery benchmark world

The repository has breadmaking legacy data and a strong steam-sterilisation dogfood project, but not a realistic bakery constraint benchmark designed for solver evaluation.

Need sparse facts, hard constraints, gold checks, difficulty tiers
Final-year projectwith bakery domain expert
Evaluation

No research evaluation protocol

“Produces a valid timeline” is necessary but insufficient. The project needs baselines, validity rate, solve time, diversity, edit cost, plausibility, and blinded expert assessment.

Domain expert not identified
no benchmark metrics or baseline solver
Project proposalagree with supervisor
Stretch

Dense timeline → causal simulator is absent

There is no inference layer that learns inspectable rules from completed histories or tests those rules on unseen situations. This remains correctly outside near-term course scope.

Generator is hand-authored
no rule induction or holdout scenarios
Stretch goalprotect core project first

The key semantic fork

If a Change is a discrete immutable fact attached to a task boundary, the current model is already strong. If it must be a continuously evaluable mathematical shape, the repository needs a new declarative curve abstraction—not more freedom inside today’s callbacks.
